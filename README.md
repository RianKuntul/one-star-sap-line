A one-star review written in sap: a houseplant reviews the human who
owns it. Its owner moved it to the bathroom "for the humidity", so it
now lives in the dark listening to his shower — a spa prisoner who
hasn't seen the sun since March.

## Run

```sh
node main.ts
```

Writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`), after self-validating the gate: exactly one line,
1–279 characters, no trailing newline.
